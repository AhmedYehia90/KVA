# Event Catalog

Events use `domain.entity.action` naming and a versioned envelope with organization, aggregate, actor, correlation, causation, time, payload, and metadata.

Core examples: `flight.booked`, `aircraft.assigned`, `dispatch.created`, `flight.completed`, `pirep.created`, `pilot.promoted`, `salary.paid`, `legacy.moment_created`, `story.entry_created`, `airport.status_changed`, `global_event.started`, `mentor.debrief_created`.
