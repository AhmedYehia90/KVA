# KVA Constitution

1. KVA is a virtual aviation platform, not only a virtual airline website.
2. The pilot is the hero of the product.
3. Every completed flight must change something meaningful.
4. AI assists, teaches, and recommends.
5. Progress is permanent.
6. History is archived rather than erased.
7. Legacy is earned.
8. Every domain has one source of truth.
9. Capabilities communicate through versioned domain events.
10. Major capabilities are documented before implementation.

## Pilot Data Protection & Privacy

- Full names, email addresses, credentials and private account identifiers are private. Public pages and public APIs must not disclose them.
- Public identity uses a pilot callsign. A public passport requires the pilot's explicit public-visibility choice; private or inactive passports remain unavailable to visitors.
- A pilot may access their own private profile. Access to other pilots' personal information is restricted to authorized, active staff for a legitimate operational purpose.
- Profile editing must not allow pilots to change their role, account status, flight totals or other authority-bearing fields.
- Privacy is enforced at the server, API and database permission boundaries, not by hiding text with CSS. Public responses use an explicit field allowlist.
- Pilots may request access, correction, deletion or restriction through the airline's established administration channel. Identity is verified before a request is handled.
- Retain only information needed for platform operations, security and documented audit requirements. Review deletion requests and restrict or de-identify retained records where appropriate.
- External-account connections and additional tracking require a separate, disclosed purpose and appropriate authorization. Never publish credentials or personal data in logs or exports intended for the public.

## حماية بيانات الطيارين وخصوصيتهم

- الأسماء الكاملة وعناوين البريد الإلكتروني وبيانات الدخول ومعرّفات الحساب الخاصة بيانات غير عامة، ولا يجوز كشفها في الصفحات أو واجهات API العامة.
- تُعرض الهوية العامة باستخدام رمز نداء الطيار. يتطلب الجواز العام اختيار صاحبه إظهاره للعامة صراحةً؛ ولا تتاح الجوازات الخاصة أو غير النشطة للزوار.
- يحق للطيار الوصول إلى ملفه الخاص، ويقتصر الوصول إلى بيانات الآخرين على الموظفين النشطين المخوّلين ولغرض تشغيلي مشروع.
- لا يجوز أن يتيح تعديل الملف الشخصي تغيير الدور أو حالة الحساب أو إجماليات الرحلات أو الحقول التي تمنح صلاحيات.
- تُفرض الخصوصية في الخادم وواجهات API وصلاحيات قاعدة البيانات، وليس بإخفاء النصوص بالتنسيق. تقتصر الاستجابات العامة على قائمة صريحة من الحقول المسموح بها.
- يجوز للطيار طلب الاطلاع أو التصحيح أو الحذف أو تقييد المعالجة عبر قناة إدارة الشركة المعتمدة، بعد التحقق من الهوية.
- يُحتفظ بالمعلومات اللازمة للتشغيل والأمان ومتطلبات التدقيق الموثّقة فقط، وتُراجع طلبات الحذف مع تقييد السجلات المحتفظ بها أو إزالة هويتها حيثما أمكن.
- يتطلب ربط الحسابات الخارجية والتتبّع الإضافي غرضًا معلنًا وتفويضًا مناسبًا، ويُمنع نشر بيانات الدخول أو البيانات الشخصية في السجلات أو الصادرات المخصّصة للعامة.
