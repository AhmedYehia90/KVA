# Mentor AI

Mentor AI is the adaptive learning layer for KVA OS pilots.

## Purpose

Digital Flight Companion explains a completed flight. Mentor AI takes the next
step: it selects one practical learning focus, turns it into a lesson, records
the pilot's reflection and tracks measurable goals across later flights.

## v1.0 capabilities

- One primary focus per debrief
- Tone-aware opening message
- Evidence-backed diagnosis
- Phase-based lesson plan
- Pilot reflection responses
- Custom reflection note
- Recommended measurable goal
- Automatic goal progress from future debriefs
- Pause, resume and complete goal controls
- Private pilot-only data

## Goal categories

- Landing control
- Timing control
- Data discipline
- Record awareness
- Consistency

## Trust boundary

Mentor AI v1.0 uses only Digital Flight Companion and Black Box Replay
evidence. It does not invent navigation procedures, VOR instructions,
simulator telemetry, aircraft behaviour or unrecorded events.
