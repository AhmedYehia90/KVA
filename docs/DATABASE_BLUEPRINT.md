# Database Blueprint

## Existing operational domains
profiles, ranks, airports, routes, fleet_types, aircraft, flight_bookings, dispatches, flight_events, pireps.

## Planned foundation domains
organizations, organization_memberships, platform_events, event_processing_log, business_rules, rule_evaluations, legacy_moments, legacy_moment_sources, pilot_passports, pilot_wallets, wallet_transactions, pilot_flight_metrics, pilot_dna_snapshots, airline_story_entries.

## Principles
- Immutable financial ledger
- Auditable events and rule decisions
- Explicit organization scope
- Separate external and internal identifiers
- Least-privilege access
