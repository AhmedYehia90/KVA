# Contributing to KVA OS

## Branches
- `main`: stable
- `develop`: integrated development
- `feature/*`: capability work
- `fix/*`: corrective work

## Commit prefixes
`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`

## Required for major capabilities
Blueprint, Business Rules, Event Map, Data and Privacy Review, Test Plan, Release Notes.
