# Contributing to KVA OS

## Branches

- `main`: stable
- `develop`: integrated development
- `feature/*`: capability work
- `fix/*`: corrective work

## Commit prefixes

- `feat:`
- `fix:`
- `docs:`
- `refactor:`
- `test:`
- `chore:`

## Every major capability requires

1. Blueprint
2. Business Rules
3. Event Map
4. Data and privacy review
5. Test plan
6. Release notes
