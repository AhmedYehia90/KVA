# KVA OS

> **Build Your Aviation Career. Fly Your Story. Leave a Legacy.**

**KVA OS** is a next-generation Virtual Aviation Operating System for virtual pilots, virtual airlines, operations teams, and connected aviation communities.

**Kalabsha Airlines** is the founder airline and the first airline powered by KVA OS.

KVA OS is built as a modular, event-driven, multi-airline-ready platform where every flight can become part of a pilot's identity, operational history, learning journey, achievements, economy, long-term legacy, and connected aviation world.

# Event-Driven Foundation

KVA OS is built around an Event Platform rather than isolated CRUD screens.

Important flight and platform actions are recorded as domain events, allowing multiple systems to react without tightly coupling every feature together.

Examples include:

- `flight.booked`
- `aircraft.assigned`
- `dispatch.created`
- Flight lifecycle events
- PIREP events
- Passport events
- Smart Operations events
- Global Aviation Events
- Career & Economy events
- Museum curation events
- Living Airports notice events

This foundation powers:

- Operations projections
- Black Box Replay
- Smart Operations AI
- Digital Flight Companion
- Mentor AI
- Living Airbot
- Global Aviation Events
- Career & Economy
- Museum / History
- Living Airports

# Testing Philosophy

A KVA OS capability is not considered complete just because a screen renders.

Major releases should verify:

1. Package typecheck
2. Package tests
3. Package build
4. Web production build
5. Supabase migration synchronization
6. Manual end-to-end validation
7. Data-integrity invariants
8. Git staged-diff review
9. GitHub CI
10. Deployment checks

---

# Finalization Safety

Local installer and packaging artifacts must not be accidentally committed.

Do not use:

```text
git add .
```

Sensitive/local-only examples include:

- `.env`
- `apps/web/.env.local`
- local installer / verifier / rollback scripts
- package payload directories
- local checksum / rollback / packaging manifests

Final staging should always use an explicitly reviewed path list.

**Kalabsha Airlines is where the story started. KVA OS is where the ecosystem grows.**
