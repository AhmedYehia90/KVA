# @kva/career-economy

Career & Economy v1.0 is the evidence-backed progression and economy layer for
KVA OS.

The package intentionally separates:

- Pilot Career + Pilot Wallet + Pilot Marketplace
- Company Economy + Company Marketplace + fleet/company purchasing authority

Both sides are reconciled through one append-only Economy Ledger.

Core rules:

- No flight → no salary.
- No evidence → no reward.
- No ledger entry → no balance change.
- Pilot route support is an interest signal, not route authority.
- Aircraft and fleet decisions remain company-only.
