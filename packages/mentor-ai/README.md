# @kva/mentor-ai

Explainable adaptive mentoring for KVA OS pilots.

## v1.0

- Converts Digital Flight Companion debriefs into practical lessons
- Selects one primary focus
- Provides phase-based guidance
- Supports pilot reflections
- Recommends measurable learning goals
- Tracks goal progress across later debriefs
- Separates platform-record warnings from pilot-performance judgment

Mentor AI v1.0 is deterministic and evidence-backed. It does not invent
navigation procedures, simulator telemetry or aircraft behaviour.
