# @kva/digital-flight-companion

Explainable post-flight debrief and coaching policies for KVA OS.

## v1.0 evidence

- Landing rate
- Actual versus planned block time
- Fuel-data completeness
- Black Box Replay integrity

## Principles

- Encouraging but honest
- Evidence-backed
- Pilot-facing
- No invented telemetry
- System integrity warnings are not treated automatically as pilot faults
